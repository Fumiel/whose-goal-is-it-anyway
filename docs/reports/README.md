# 進捗報告

指導教員向けの進捗報告は、[共通テンプレート](progress_report_template.md)と[作成ルール](progress_report_rules.md)に従って作成する。テンプレートには報告書の構成と記入欄、ルールには情報源の確認順と記述・提出時の確認事項をまとめた。新しい報告書を作る際は両方を読む。

既存の報告書は各時点で提出・共有された記録であり、現在の研究計画や実験手順を定めるものではない。現在の作業状況は[PROJECT_STATE.md](../../PROJECT_STATE.md)、研究目的は[研究計画書](../research_proposal.md)、実験手順は[実験プロトコル](../experimental_protocol.md)を参照する。
